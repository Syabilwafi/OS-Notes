# Operating System Notes and Resources
--- 
This repository contains a structured set of Markdown notes, diagrams, and resources for studying Operating System concepts, organized specifically for Obsidian.

# Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/operating-systems-notes.git
```

Open in Obsidian:
- Open Obsidian.
- Select "Open folder as vault".
- Navigate to and select the cloned directory.

Start Navigating:
Open ```Operating Systems Map of Content (MOC).md``` to start exploring topics from the central hub.
